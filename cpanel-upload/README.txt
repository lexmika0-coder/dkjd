Upload these files from the cpanel-upload folder into your cPanel public_html directory.

Files included:
- index.html
- styles.css
- script.js

Notes:
- This package is a static site and works with any standard cPanel hosting setup.
- To deploy: upload the folder contents into public_html, or upload the folder itself and use its index.html as the homepage.
- If you want the page to submit to your own backend, replace the JavaScript form logic with your real login endpoint.
